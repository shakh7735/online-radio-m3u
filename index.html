Логотипы

Скачиваются один раз в logos/ рядом с приложением; уже имеющиеся файлы не перекачиваются.

GitHub — хостинг логотипов

Выбери «GitHub raw» в списке ссылок выше — секция включится.

токен не задан
Personal access token

github.com/settings/tokens → classic со scope public_repo, либо fine-grained с правом Contents: read and write на нужный репозиторий. Токен хранится только локально, в github-token.txt.

Файл, который уже есть в репозитории, повторно не заливается. Репозиторий должен быть публичным — иначе raw-ссылки не откроются в плеерах.

Google Drive

Выбери «Google Drive» в списке ссылок выше — секция включится.

не подключено
Google блокирует вход? Вставить access token вручную

Скоуп Drive «ограниченный», поэтому клиент gcloud (или политика рабочего домена) может блокировать вход. Обход: получи токен в OAuth 2.0 Playground для скоупа https://www.googleapis.com/auth/drive и вставь сюда. Токен живёт ~1 час — этого хватит: ID файлов кэшируются и переиспользуются потом всегда.

Вход выполняется через gcloud и запоминается — при следующем запуске повторно логиниться не нужно. Файлы заливаются один раз и получают доступ «для всех, у кого есть ссылка», иначе плееры не покажут логотип.
