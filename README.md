# top-radio → M3U

Локальное приложение: собирает радиостанции с [top-radio.ru](https://top-radio.ru) (Армения и Россия),
скачивает логотипы, публикует их на GitHub и собирает M3U-плейлист. Справа — плеер для проверки.

## Запуск

Нужен Node.js 22+ (используется `--experimental-strip-types`, TypeScript запускается напрямую).

```bash
# двойной клик по файлу
index.command

# или из терминала
npm start
```

Откроется `http://localhost:8787`. Локальный сервер нужен потому, что top-radio.ru не отдаёт
CORS-заголовки — из браузера напрямую его страницы не прочитать.

## Слева: парсер

- **Страна** — Армения или Россия. **Город** — опционально: пусто = топ станций страны
  (Армения 18, Россия 100), иначе станции конкретного города (списки по городам берутся из `sitemap.xml`,
  потому что на самих страницах города они рисуются JS-ом).
- **Проверять потоки** — прогоняет каждый поток ranged-GET'ом и помечает `online` / `offline`.
- **Логотипы** — скачиваются один раз в `logos/`; файл, который уже на диске, не перекачивается.
- **Плейлист** — битрейт (max/min/все), скачать M3U или сохранить рядом с приложением.

## Справа: плеер

Играет прямые mp3/aac потоки через `<audio>`. HLS (`.m3u8`) Safari играет нативно;
для Chrome/Firefox есть кнопка, которая один раз скачивает `hls.js` в `vendor/`.
Кнопка «Загрузить .m3u» открывает любой существующий плейлист для проверки.

## Хостинг логотипов

В плейлист можно писать разные ссылки на логотипы — выбор в списке «Ссылки на логотипы в плейлисте»:

- **GitHub raw** (рекомендуется) — логотипы заливаются в публичный репозиторий через Contents API,
  в M3U идут ссылки `raw.githubusercontent.com/...` (или jsDelivr). Нужен personal access token:
  classic со scope `public_repo` либо fine-grained с правом `Contents: read and write`.
  Файл, который уже есть в репозитории, повторно не заливается.
- **Google Drive** — работает, но Drive-скоуп «ограниченный», поэтому вход через gcloud
  часто блокируется Google или политикой рабочего домена; есть обход через вставку access token.
- **Свой базовый URL** / **локальный путь** / **ссылки самого top-radio.ru**.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.command` | лаунчер: поднимает сервер и открывает страницу |
| `index.html` | интерфейс: парсер + плеер |
| `top-radio-app.ts` | локальный сервер и его API |
| `top-radio-core.ts` | парсинг top-radio.ru, скачивание логотипов, проверка потоков |
| `top-radio-github.ts` | публикация логотипов и проекта на GitHub |
| `top-radio-drive.ts` | загрузка логотипов на Google Drive |

Токены (`github-token.txt`, `drive-token.txt`) и локальное состояние в git не попадают — см. `.gitignore`.

## Аккуратность к сайту

`robots.txt` top-radio.ru запрещает URL с query-строкой — приложение такие не запрашивает.
Запросы идут с задержкой (4 воркера, 250 мс), HTML кэшируется на сутки в `.cache/`.

Логотипы принадлежат самим радиостанциям — публикуя их в публичном репозитории, ты их распространяешь;
для личного плейлиста это обычная практика, но стоит помнить.
